# Recruitment & Placement Management System – UI Prototype

## Included
- 12 static HTML pages
- Shared responsive stylesheet (`css/style.css`)
- Sample records and cross-page navigation
- No backend, database, or data persistence (as specified)

## Run
1. Extract the ZIP file.
2. Open `login.html` in a browser.
3. Select any role and click Login to open the dashboard.
4. Use the sidebar and page action links to navigate through the prototype.

## Notes
Forms are visual prototypes. Login, save, search, and workflow buttons do not connect to a server or persist data. The Login button navigates to the dashboard.
